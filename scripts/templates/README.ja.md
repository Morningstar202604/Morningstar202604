## プロフィール

抽象的なアイデアを触れるインターフェースに落とし込む開発者。フルスタックとクリエイティブなツール作りを中心に、シンプルで質感のあるデザインを好み、画一的なテンプレートを嫌う。コードも星空も同じで、巧みさは細部に宿る。

- **最近取り組んでいること**：インタラクティブな可視化、自動化ワークフロー、思わず頷ける小道具
- **よく使う言語**：TypeScript / Python / Rust
